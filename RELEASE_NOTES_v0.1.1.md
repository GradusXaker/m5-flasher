# Gradus Flasher v0.1.1

Патч-релиз с релизной полировкой и подготовкой к удобной дистрибуции.

## Что нового

- добавлена встроенная иконка приложения
- добавлена история последних операций в интерфейсе
- добавлены реальные скриншоты окна и мастера прошивки в `README.md`
- добавлена проверка обновлений по последнему релизу в центре релизов
- добавлена автоматическая Windows-сборка через GitHub Actions

## Что улучшено

- релизный процесс стал ближе к полноценной поставке продукта
- подготовлена автоматическая загрузка Windows-артефакта в GitHub Releases по тегу
- README теперь показывает текущий интерфейс приложения визуально

## Артефакты

- Linux: архив `GradusFlasher-linux-v0.1.1.tar.gz`
- Windows: после выполнения workflow появится `GradusFlasher-windows-v0.1.1.zip`
