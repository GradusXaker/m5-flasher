# Быстрая установка на Windows

Если ты хочешь просто скачать и запустить готовую версию без сборки из исходников, используй GitHub Release.

## Важно

Репозиторий `GradusXaker/m5-flasher` сейчас приватный.

Это значит:

- нужно быть залогиненным в GitHub под аккаунтом, у которого есть доступ;
- иначе файлы релиза могут не отображаться или не скачиваться.

## Что скачать

Открой релиз:

- `https://github.com/GradusXaker/m5-flasher/releases/tag/v0.1.3`

Дальше смотри блок `Assets`.

Там есть два Windows-файла:

- `GradusFlasher-Setup-v0.1.3.exe` — обычная установка через инсталлятор
- `GradusFlasher-windows-v0.1.3.zip` — portable-версия без установки

## Что выбрать

### Вариант 1. Обычная установка

Скачай:

- `GradusFlasher-Setup-v0.1.3.exe`

Дальше:

1. Запусти файл двойным кликом.
2. Если Windows покажет предупреждение SmartScreen, нажми `Подробнее` -> `Выполнить в любом случае`.
3. Пройди шаги установщика.
4. После установки запусти `Gradus Flasher` из меню `Пуск` или с рабочего стола.

### Вариант 2. Portable без установки

Скачай:

- `GradusFlasher-windows-v0.1.3.zip`

Дальше:

1. Распакуй архив в любую папку.
2. Открой папку `GradusFlasher`.
3. Запусти `GradusFlasher.exe`.

Если хочешь, чтобы настройки хранились рядом с программой, а не в системе:

1. Создай рядом с `GradusFlasher.exe` файл `portable.ini`
2. После этого приложение перейдет в portable-режим

## Если не видишь .exe в релизе

Проверь по пунктам:

1. Ты точно вошел в GitHub под нужным аккаунтом
2. Ты открыл вкладку `Assets` у релиза `v0.1.3`
3. Ты смотришь именно репозиторий `GradusXaker/m5-flasher`
4. Репозиторий не открыт в анонимном режиме браузера
