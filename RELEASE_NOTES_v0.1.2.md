# Gradus Flasher v0.1.2

Релиз с установщиком, portable-режимом и landing-page проекта.

## Что нового

- добавлен Windows installer на базе Inno Setup
- Windows workflow теперь публикует не только `.zip`, но и installer `.exe`
- добавлен portable-режим через файл `portable.ini`
- добавлен экспорт логов в `.log` или `.txt`
- добавлена landing-page проекта `docs/index.html`

## Что улучшено

- удобнее распространять Windows-версию среди обычных пользователей
- настройки теперь можно хранить рядом с приложением в portable-режиме
- README и docs стали ближе к полноценной презентации проекта

## Артефакты

- Linux: архив `GradusFlasher-linux-v0.1.2.tar.gz`
- Windows: архив `GradusFlasher-windows-v0.1.2.zip`
- Windows installer: `GradusFlasher-Setup-v0.1.2.exe`
