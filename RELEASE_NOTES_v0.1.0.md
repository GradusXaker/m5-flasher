# Gradus Flasher v0.1.0

Первая релизная версия `Gradus Flasher`.

## Что вошло

- desktop-интерфейс для прошивки `M5Stick` и совместимых `ESP32`
- выбор serial/`COM`-порта и `.bin` файла
- live-лог и прогресс прошивки через `esptool`
- загрузка последней совместимой прошивки `Gradus`
- onboarding и пошаговый мастер прошивки
- проверка устройства, определение чипа и подсказка профиля
- анализ `.bin` перед записью
- крупный блок готовности к прошивке
- история последних операций
- встроенный центр релизов Gradus
- инструкции для установки и сборки под Windows

## Что важно

- приложение уже проверено в Linux-окружении и успешно собирается через `PyInstaller`
- для Windows подготовлены сценарий сборки `build-windows.bat` и инструкция `BUILD_WINDOWS.md`
- автоподбор профиля сейчас лучше всего работает для `ESP32-S3` (`M5Stick S3`)

## Следующие шаги

- нативная Windows-сборка `.exe`
- релизные артефакты для скачивания из GitHub Releases
- расширение списка встроенных профилей устройств
