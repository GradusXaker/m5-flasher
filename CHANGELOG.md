# Changelog

## v0.1.1

- добавлены встроенная иконка приложения и branding assets
- добавлена история последних операций с сохранением между запусками
- добавлены скриншоты интерфейса в `README.md`
- добавлен баннер проекта в `README.md`
- добавлена страница `О программе` внутри приложения
- добавлена проверка обновлений по последнему релизу в центре релизов
- добавлена автоматическая Windows-сборка через GitHub Actions и публикация `.zip` в release

## v0.1.0

- создан desktop-прошивальщик `Gradus Flasher` для `M5Stick` и совместимых `ESP32`
- добавлены выбор serial-порта, выбор `.bin`, live-лог и прогресс прошивки
- добавлены загрузка последнего `Gradus`, wizard первого запуска и onboarding
- добавлены проверка устройства, автоопределение чипа и подсказка профиля
- добавлены анализ `.bin`, статус готовности к прошивке и история операций
- добавлены центр релизов, инструкции для Linux/Windows и сценарий сборки `.exe`
