# История изменений

```text
> repo: m5-flasher
> doc: CHANGELOG
> purpose: Ключевые изменения и история релизов Gradus Flasher
```


## v0.1.5

- `Gradus Flasher` переключен на загрузку прошивок из `gradus-firmware`
- профили прошивок теперь используют единые бинарники `Gradus-*`
- центр релизов в приложении теперь отражает firmware-релизы `gradus-firmware`

## v0.1.4

- исправлена совместимость с `esptool 5.2`: probe и flash переведены на новые команды и флаги
- исправлен разбор ответа `ESP32-S3`, включая `Chip type`, `Features` и `MAC`

## v0.1.3

- исправлен критический баг packaged Windows-версии: вызовы `esptool` больше не запускают новый экземпляр приложения
- probe, analyze и flash теперь работают через прямую интеграцию с `esptool` внутри процесса

## v0.1.2

- добавлен Windows installer через Inno Setup и GitHub Actions
- добавлены portable-режим через `portable.ini` и сохранение настроек в локальный `.ini`
- добавлен экспорт логов в файл из интерфейса
- добавлена landing-page проекта в `docs/index.html`

## v0.1.1

- добавлены встроенная иконка приложения и branding assets
- добавлена история последних операций с сохранением между запусками
- добавлены скриншоты интерфейса в `README.md`
- добавлен баннер проекта в `README.md`
- добавлена страница `О программе` внутри приложения
- добавлена проверка обновлений по последнему релизу в центре релизов
- добавлена автоматическая Windows-сборка через GitHub Actions и публикация `.zip` в release

## v0.1.0

- создан desktop-прошивальщик `Gradus Flasher` для `M5Stick` и совместимых `ESP32`
- добавлены выбор serial-порта, выбор `.bin`, live-лог и прогресс прошивки
- добавлены загрузка последнего `Gradus`, wizard первого запуска и onboarding
- добавлены проверка устройства, автоопределение чипа и подсказка профиля
- добавлены анализ `.bin`, статус готовности к прошивке и история операций
- добавлены центр релизов, инструкции для Linux/Windows и сценарий сборки `.exe`
