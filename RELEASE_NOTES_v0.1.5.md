# Gradus Flasher v0.1.5

```text
> repo: m5-flasher
> doc: RELEASE_NOTES
> purpose: Release notes для версии v0.1.5
```


Релиз, который связывает flasher и отдельный репозиторий прошивок `gradus-firmware`.

## Что изменилось

- кнопка загрузки прошивок теперь использует `https://github.com/GradusXaker/gradus-firmware`
- профили `M5Stick` переведены на бинарники `Gradus-*`
- центр релизов внутри приложения показывает актуальный firmware-релиз

## Что это дает

- один понятный источник прошивок
- меньше путаницы с `BruceDevices/firmware` и upstream-именами
- проще скачивать правильный `.bin` прямо из `Gradus Flasher`

## Артефакты

- Linux: `GradusFlasher-linux-v0.1.5.tar.gz`
- Windows: `GradusFlasher-windows-v0.1.5.zip`
- Windows installer: `GradusFlasher-Setup-v0.1.5.exe`
