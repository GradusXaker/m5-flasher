# Gradus Notes

Цель проверки:

- `Bruce-m5stack-sticks3.bin`
- актуальный релиз на момент проверки: `1.14`

Что уже проверено:

- бинарник корректно открывается через `esptool image-info`
- определенный чип: `ESP32-S3`
- режим flash: `DIO`
- частота flash: `80m`
- заявленный размер flash: `8MB`

## Что уже хорошо

- готовые бинарники удобно находить через GitHub releases upstream-проекта
- single-image сценарий прошивки хорошо подходит для `esptool`
- для `M5Stick S3` бинарник именуется предсказуемо: `Bruce-m5stack-sticks3.bin`

## Что еще можно улучшить вокруг Gradus

- onboarding в web-flasher слишком техничный для первого запуска
- выбор устройств лучше показывать карточками и с заметками по платам
- на странице есть промежуточные состояния с неаккуратной загрузкой данных
- для `M5Stick` нужны более наглядные инструкции по `G0`, `GND` и boot mode
- стоит автоматически подсвечивать рекомендуемую прошивку под выбранную плату

## Что уже улучшает это приложение

- desktop-прошивка без зависимости от браузерного WebSerial
- понятный выбор `COM`/serial-порта
- живой лог процесса и прогресс-бар
- загрузка последней совместимой сборки в один клик для поддерживаемых профилей `M5Stick`
- сохранение последних настроек для быстрых повторных прошивок
