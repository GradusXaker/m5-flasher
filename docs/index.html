Gradus Flasher

Хакерский desktop-прошивальщик для M5Stick и совместимых ESP32-плат. Один интерфейс для проверки устройства, анализа .bin, подбора профиля, скачивания релизов и самой прошивки.

Скачать релизы GitHub Установка Windows
Device check
Определение чипа, flash и связи до прошивки.
Firmware analyze
Проверка `.bin` через `esptool image-info`.
Release center
Просмотр релизов и проверка обновлений прямо в приложении.

Главное окно

Мастер прошивки

Что умеет

  • выбор COM / serial-порта
  • live-лог и прогресс прошивки
  • автоподбор профиля
  • история операций

Релизный процесс

  • Linux архив публикуется вручную
  • Windows zip собирается GitHub Actions
  • Windows installer собирается автоматически
  • обновления видны в release center

Для кого

  • M5Stick S3
  • M5StickC Plus2
  • M5StickC Plus 1.1
  • другие совместимые ESP32
